# 핫스팟 프록시 개인정보처리방침

시행일: 2026년 11월 16일

핫스팟 프록시(이하 "앱")는 사용자의 개인정보를 수집하지 않습니다.

## 수집하는 정보

앱은 어떤 개인정보도 수집, 저장, 전송하지 않습니다. 앱에는 광고, 분석 도구, 계정 기능이 없습니다.

## 앱이 다루는 데이터

- 프록시 통신: 핫스팟에 연결한 기기의 통신을 인터넷으로 그대로 전달합니다. 통신 내용을 기록하거나 저장하지 않습니다.
- 통신량: 보낸 양(TX)과 받은 양(RX)을 화면에 보여 주려고 폰 안에서만 셉니다. 이 값은 밖으로 보내지 않고, 프록시를 다시 켜면 지워집니다.
- 설정: 포트 번호 같은 설정은 폰 안에만 저장합니다.

## 권한

- 인터넷, 네트워크 상태: 프록시 통신을 전달하고 핫스팟 주소를 보여 줍니다.
- 알림, foreground service: 프록시가 켜져 있는 동안 알림을 띄우고 백그라운드에서 계속 동작합니다.
- 부팅 완료 수신: 폰을 다시 켰을 때 프록시를 다시 켭니다.
